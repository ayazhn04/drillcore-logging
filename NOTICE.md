# Notice: relation to Serdoun et al. (2026)

This project is an **independent, clean-room reimplementation** of the workflow described in:

> Serdoun, M., Sur, F., Milési, G., Obin, T., Mercadier, J. (2026). *Automated classification of drill core photographs: A complete workflow for weakly supervised training.* Computers & Geosciences 212, 106156. https://doi.org/10.1016/j.cageo.2026.106156. The article is published under CC BY 4.0.

- The authors' code (https://github.com/MehdiSerdoun/Core-photographs) has **no license file**, so its reuse rights are not granted. **No code from that repository is included here.** It was only read and tested, in a separate folder outside this repository, for the reproduction audit ([docs/REPRODUCTION_AUDIT.md](docs/REPRODUCTION_AUDIT.md)).
- The methods implemented here follow the published article (equations, architecture descriptions, hyperparameters), with the corrections documented in the audit and in [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md).
- Please cite the article when using this workflow.
